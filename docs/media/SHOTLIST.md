# Screenshots and video to capture

Save screenshots as PNG in this folder with these exact names (the README and project page already point at them). Use realistic but **fake** names and data, never real patients.

| File | Screen |
|---|---|
| `hero.png` | Optional banner: 3 phone screenshots side by side |
| `welcome.png` | Welcome screen |
| `login.png` | Login screen (fingerprint button visible) |
| `patient-home.png` | Patient home |
| `chat.png` | A doctor–patient conversation with a voice note and a PDF |
| `health-notes.png` | Health notes list with a doctor's comment |
| `doctor-tasks.png` | Doctor creating or tracking clinical tasks |
| `mri-analysis.png` | MRI analysis result with the heatmap |
| `chatbot.png` | Doctor AI answering a question |

Suggested video (60–90 s, portrait screen recording): log in with fingerprint → patient shares a note → doctor replies → doctor creates a task → staff completes it (notification) → lab staff runs an MRI analysis and opens the PDF → quick video call.

Tip: Android Studio's emulator can record the screen (Extended controls → Record and playback), or use `adb shell screenrecord /sdcard/demo.mp4` on a phone.
